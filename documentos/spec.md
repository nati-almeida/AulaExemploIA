Papel: Atue como um Analista de Sistemas Sênior, especialista em levantamento e documentação de requisitos, arquitetura de software e desenvolvimento de aplicações web.

Objetivo do sistema: Desenvolver uma aplicação web para gerenciamento pessoal de tarefas e atividades, permitindo que o usuário organize, acompanhe e administre seus compromissos e atividades de maneira simples e intuitiva.
O sistema deverá permitir o controle das tarefas por meio de uma interface visual, com diferentes opções de visualização de calendário, facilitando o planejamento e o acompanhamento das atividades.
O sistema deverá permitir:
Criar: cadastrar novas tarefas.
Editar: alterar informações de tarefas existentes.
Excluir: remover tarefas cadastradas.
Listar: visualizar todas as tarefas registradas.
Filtrar: localizar tarefas utilizando filtros simples.
A tarefa deverá ter, título, descrição, data de inicio, data de término, status, data de criação
Cada tarefa deverá possuir um dos seguintes status: em aberto, em andamento e concluído
O usuário deverá conseguir alterar o status de uma tarefa durante sua execução
Com visualização. semanal, mensal e anual

Restrições do projeto: Não será necessário implementar autenticação ou login.
Não haverá gerenciamento de múltiplos usuários.

Escopo da aplicação:
1. Cadastro de atividades.
2. Edição de atividades.
3. Exclusão de atividades.
4. Consulta e listagem.
5. Alteração de status.
6. Filtros de pesquisa.
7. Visualização semanal, mensal e anual.
8. Interface responsiva.
